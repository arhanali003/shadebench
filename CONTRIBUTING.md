# Contributing

Start with a question that can fail. Include a small redistributable fixture,
expected behavior and the check that distinguishes success from failure. Run the
full unit suite and a fresh demo before sending a change.

Keep clean and random controls, do not optimize on evaluation images, and report
all seeds and failed runs. A feature-space shift is not evidence of protection.
New model backends need model-license documentation and separate evaluation; do
not quietly relabel the toy experiment as a diffusion reproduction.

Only submit code/data/artwork you can redistribute. Do not add private images,
credentials or invented research results. The project welcomes human review and
AI-assisted contributions; both are held to the same evidence requirements.
